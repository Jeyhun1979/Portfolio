## 🏆 Главные проекты (React & REST API)

Каждый из этих проектов работает с реальными данными сервера и демонстрирует навыки построения архитектуры веб-приложений.

### 📌 1. Дипломный проект курса "Frontend-разработчик"
* **Описание:** Финальная выпускная работа расширенного курса. Полноценное масштабное SPA-приложение, демонстрирующее комплексное владение экосистемой React и интеграцию сложной бизнес-логики.
* **Технологии:** React, React Router, Управление состоянием, Асинхронные запросы, REST API.
* **Ссылки:** [💻 Исходный код](https://github.com/Jeyhun1979/frontend_diplom) | [🌐 Живое демо (Сайт)](https://jeyhun1979.github.io/frontend_diplom/)

### 💱 2. Конвертер валют (Case_converter)
* **Описание:** Динамический калькулятор для быстрого перевода сумм между различными мировыми валютами. Работает на **реальных асинхронных запросах к API** валютных курсов. Успешно обрабатывает ошибки сети и валидирует числовой ввод пользователя.
* **Технологии:** React, Hooks (useState, useEffect), Fetch / Axios, REST API, Работа с формами.
* **Ссылки:** [💻 Исходный код](https://github.com/Jeyhun1979/case_converter) | [🌐 Живое демо (Сайт)](https://jeyhun1979.github.io/case_converter/)

### 📰 3. Новостной агрегатор (Case_news)
* **Описание:** Информационный сервис, который **в реальном времени запрашивает свежие новости через REST API**. Реализована фильтрация контента по категориям, обработка состояний загрузки (спиннеры/скелетоны) и адаптивная сетка под любые экраны.
* **Технологии:** React, React Hooks, CSS-модули (модульные стили), REST API, Асинхронный JS.
* **Ссылки:** [💻 Исходный код](https://github.com/Jeyhun1979/case_news) | [🌐 Живое демо (Сайт)](https://jeyhun1979.github.io/case_news/)
